# 연구소 UI 점검·리뉴얼 기록 (2026-11-06)

## 바뀐 것 (UI만, 수집·분석·발행 코드는 안 건드림)
- 색: 바탕을 중성 회색(#f8f9fb), 글자 #17202b, 카드 모서리 12px. 라즈베리(#b8336a)는 강조에만. 다크모드 유지(시스템 설정 따름).
- 왼쪽 메뉴를 6개 묶음으로: 대시보드 · 트렌드 발견 · 계정 분석 · 콘텐츠 제작 · 성과 분석 · 발행 캘린더. 기존 메뉴 15개는 하나도 빠지지 않고 묶음 안으로 이동.
- 대시보드 숫자 4칸: 주목 콘텐츠(thx_top 개수) · 급상승(thx_rising) · 제작 후보(recs, drafts) · 검수·발행 대기(로그인해야 보이는 큐라 '측정 불가'로 표시).
- 지금 주목할 콘텐츠: 바이럴 TOP·급상승에서 중복 없이 4개.
- 쓰레드 인사이트: 탭(바이럴 TOP·급상승·지금 크는 글·10만+·내 계정), 검색, 정렬, 24개씩 더 보기. 카드를 누르면 오른쪽 상세 패널(ESC·바깥 클릭으로 닫힘).
- 상세 패널: 본문 전체, 실측 지표(관측 데이터 표시), 지표 정의 툴팁, 조회수 변화(지금 크는 글), 자동 분류(규칙 기반 표시), 목록 단위 AI 해석(AI 추정 표시), 원문 열기·본문 복사.
- 미수집 값은 0이 아니라 '미수집'으로 표시. 쓰레드 데이터에는 이미지가 없어 이미지 없이 글 미리보기만 씀(가짜 이미지 없음).
- 발행 캘린더: calendar.json 7일 계획을 카드로. 다른 계획(인스타 이번 주·7일 계획·텔레그램 오늘 문구)으로 가는 링크.
