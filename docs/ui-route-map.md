# 연구소 주소·메뉴 지도 (2026-11-06 리뉴얼)

화면 이름(data-view)은 그대로라서 예전 주소·북마크가 모두 같은 화면을 엽니다.

| 상위 메뉴 | 화면 | 예전 주소 |
|---|---|---|
| 대시보드 | 오늘 할 일 (숫자 4칸 · 지금 주목할 콘텐츠 · 데이터 갱신 · 바로가기) | `/` |
| 트렌드 발견 | 쓰레드 (맨 위 '쓰레드 인사이트' 카드 + 기존 폴더 전부) | `#ch-threads`, `#go-th-*` |
| 트렌드 발견 | 뉴스·정보 / 인스타 해외 / X·트루스 / 유튜브 | `#ch-google`, `#ch-foreign`, `#ch-x`, `#ch-youtube` |
| 계정 분석 | 계정 분석 | `#ch-accounts` |
| 콘텐츠 제작 | 인스타 한국 / 말희아빠 / 트레이더스 / 영상 / 뜬 글 공식 / 마케팅 코치 | `#ch-instagram`, `#rec-N`, `#ch-telegram`, `#ch-traders`, `#ch-video`, `#ch-viral`, `#ch-growth` |
| 성과 분석 | 활용 체크 / 후기·기록 | `#ch-usage`, `#ch-feedback` |
| 발행 캘린더 | 새 화면 (calendar.json 7일 계획) | `#ch-calendar` (새 주소) |

- 없는 `#ch-...` 주소는 첫 화면으로 보내고 "없는 주소라 첫 화면으로 왔어요"를 띄웁니다.
- `#go-폴더id` 는 그 폴더만 엽니다(기존 그대로).
