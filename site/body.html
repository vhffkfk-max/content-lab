채널별 다음 한 가지

메뉴 안내

사용 가이드

연구소가 처음이어도 5분이면 쓸 수 있게 쉽게 적었어요. 위에서부터 순서대로 읽으면 돼요.

1. 연구소가 뭐예요?

연구소는 "오늘 뭘 올릴지" 정해 주는 도우미예요.

  • 컴퓨터가 매시간 쓰레드·인스타·뉴스·텔레그램 글을 모아요.
  • 모은 글 중에서 사람들이 많이 본 글과 지금 빨리 크는 글을 골라 줘요.
  • 그걸 보고 우리 계정에 올릴 글을 만들면 돼요.

한 줄 요약: 모으기는 컴퓨터가, 고르고 올리기는 내가.

2. 하루 5분 사용 순서

  1. 대시보드 열기숫자 4칸을 봐요. 숫자가 크면 오늘 볼 글이 많다는 뜻이에요.
  2. 지금 주목할 콘텐츠 보기카드 4개 중 마음에 드는 걸 눌러요. 오른쪽에 글 전체와 숫자가 열려요.
  3. 쓰레드 인사이트 둘러보기'트렌드 발견 → 쓰레드'에서 탭을 바꿔 가며 봐요. 검색창에 "금리", "코인"처럼 넣으면 그 글만 나와요.
  4. 글 만들기'콘텐츠 제작' 메뉴에서 채널을 골라요. 인스타는 카드뉴스 검수, 텔레그램은 오늘 올릴 문구를 보면 돼요.
  5. 발행 캘린더 확인오늘 날짜 카드(테두리 색 있는 칸)에 적힌 주제·시간에 맞춰 올려요.
  6. 주 1번 성과 보기'성과 분석 → 활용 체크'에서 추천을 실제로 썼는지 확인해요.

3. 메뉴 6개, 이렇게 쓰세요

대시보드

언제? 들어오자마자

오늘 숫자, 주목할 글, 데이터가 언제 바뀌었는지, 자주 쓰는 바로가기가 있어요.

트렌드 발견

언제? 글감을 찾을 때

쓰레드 · 뉴스 · 해외 인스타 · X(트럼프 글 등)에서 요즘 뜨는 글을 봐요.

계정 분석

언제? 다른 계정이 궁금할 때

분야별 잘 나가는 계정 순위와 우리 계정 상태를 비교해요.

콘텐츠 제작

언제? 실제로 글을 만들 때

인스타 카드뉴스, 말희아빠·트레이더스 텔레그램 글, 영상, 잘 되는 글 공식, 마케팅 코치가 있어요.

성과 분석

언제? 일주일에 한 번

추천을 실제로 썼는지, 어떤 글이 잘 됐는지, 남긴 후기를 봐요.

발행 캘린더

언제? 올리기 직전

이번 주 7일 동안 무슨 주제를 몇 시에 올리면 좋은지 보여 줘요.

메뉴를 누르면 화면 위에 작은 탭이 생겨요. 탭을 누르면 그 부분만 보여요. "전체"를 누르면 다 보여요.

4. 화면에 나오는 말 뜻

조회
글을 본 사람 수예요.
확산배수
조회 ÷ 팔로워예요. 팔로워보다 몇 배 많이 봤나예요. 5배 넘으면 "모르는 사람에게도 퍼진 글"이에요.
반응률
본 사람 중 좋아요·답글·리포스트를 한 비율이에요. 3% 넘으면 좋고, 6% 넘으면 아주 좋아요.
시간당 조회
1시간에 몇 명이 봤나예요. 크면 지금 막 뜨는 글이에요.
관측 데이터
실제로 세어 본 숫자예요. 믿어도 돼요.
규칙 기반
정해진 규칙으로 컴퓨터가 나눈 것(주제, 길이 등)이에요. 가끔 틀릴 수 있어요.
AI 추정
AI가 "아마 이래서 떴을 거야"라고 생각한 거예요. 정답이 아니라 힌트로 보세요.
미수집
아직 못 모은 숫자예요. 0이라는 뜻이 아니에요.
측정 불가
이 화면에서는 셀 수 없는 숫자예요(로그인이 필요하거나 연결이 안 됨).

5. 글 카드 보는 법

  1. 카드 맨 위: 누가 썼는지(@계정), 팔로워 수, 올린 시간
  2. 가운데: 글 앞부분 3줄
  3. 아래 회색 칸: 조회 · 확산 · 반응률 숫자 3개
  4. 카드를 누르면 오른쪽에 자세히 열려요 → 글 전체, 모든 숫자, 원문 열기, 본문 복사 버튼
  5. 닫을 때는 닫기 버튼, 바깥 회색 부분, 또는 키보드 ESC

따라 쓰고 싶은 글은 "본문 복사"로 가져가서 우리 말투로 다시 쓰세요. 그대로 올리면 안 돼요.

6. 폰에서 쓰기

  • 화면 맨 아래 버튼(오늘 · 말희아빠 · 트레이더스 · 인스타 · 전체 메뉴)으로 이동해요.
  • 아래로 많이 내리면 오른쪽 아래 ↑ 버튼으로 맨 위로 가요.
  • 아이폰: 사파리 공유 버튼 → "홈 화면에 추가" 하면 앱처럼 열려요.
  • 안드로이드: 크롬 ⋮ 메뉴 → "홈 화면에 추가"

7. 자주 묻는 질문

데이터는 언제 바뀌어요?

컴퓨터가 켜져 있으면 매시간 자동으로 바뀌어요. 대시보드의 "데이터 갱신" 줄에서 마지막 시간을 볼 수 있어요. 빨간색이면 늦어진 거예요.

새로고침했는데 그대로예요.

폰은 앱을 완전히 닫았다가 다시 열어 보세요. 그래도 그대로면 그 시간에 새 글이 없었던 거예요.

버튼을 눌렀는데 "로그인" 얘기가 나와요.

카드뉴스 검수, 데이터 새로 불러오기처럼 저장이 필요한 기능은 GitHub 로그인이 필요해요. 보기만 하는 건 로그인 없이 돼요.

예전에 만든 쓰레드 글(바레이션)이 사라졌어요.

글감은 매시간 바뀌지만 만든 글은 남아요. 첫 화면 아래 "내가 만든 쓰레드 글 (지난 것까지)"에서 검색하고 복사할 수 있어요.

X(트위터) 글이 안 바뀌어요.

X가 로봇 확인을 걸어서 지금 멈춰 있어요. PC에서 crawl_login.py --x로 직접 로그인하면 다시 돌아가요.

AI 분석은 다 믿어도 돼요?

아니요. AI 추정 표시가 붙은 건 힌트예요. 숫자(관측 데이터)를 먼저 보세요.

이 사이트는 다른 사람도 볼 수 있어요?

네. 주소를 아는 사람은 누구나 볼 수 있어요. 비밀번호·개인정보는 절대 여기에 적지 마세요.

    좋아요를 숨긴 글이 많은 계정은 댓글만으로 비교해요. 경품 이벤트와 "댓글에 ‘무료’ 남기면 자료 드려요" 같은 자료 나눔형 글은 반응이 부풀려져서 추천과 순위에서 뺐어요 (행동 유도 분석에서는 따로 보여줘요).

    공식 API로는 다른 계정의 저장·공유·조회수를 볼 수 없어요. 그래서 저장·공유 유도의 효과는 좋아요·댓글로만 짐작한 값이에요.

            테스터가 공식을 만들 때 안 쓴 과거 글로 블라인드 시험을 봐요. 같은 계정의 뜬 글과 평범한 글을 숫자 없이 보여 주고 어느 쪽이 떴을지 고르게 해요(찍으면 50%). 공식을 볼 때와 안 볼 때의 정답률 차이가 공식의 실제 쓸모예요. 독자 패널(가상 독자 3명)도 같은 시험을 보고, 작가는 패널 반응으로 초안을 고쳐 써요. 하루 한 번.
