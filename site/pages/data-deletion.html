데이터 삭제 안내

말희아빠 & 파로파트너스 컨텐츠 연구소 (Content Lab)

내 쓰레드·인스타그램 게시물 데이터를 지우고 싶어요

  1. CONTACT_EMAIL 로 메일을 보내주세요.
  2. 제목에 "데이터 삭제 요청", 본문에 본인의 쓰레드 또는 인스타그램 사용자 이름(@아이디)을 적어주세요.
  3. 7일 이내에 해당 계정과 게시물 관련 데이터를 모두 삭제하고, 다시 수집하지 않도록 제외 목록에 넣은 뒤 결과를 회신드립니다.

앱 연결을 끊고 싶어요 (운영팀 계정)

쓰레드 앱 → 설정 → 계정 → 웹사이트 권한에서 "Content Lab" 연결을 삭제하면 접근 토큰이 무효가 됩니다. 저장된 토큰과 사용자 ID는 다음 자동 실행 때 지워집니다.

Data Deletion Instructions

  1. Email CONTACT_EMAIL with the subject "Data deletion request" and your Threads or Instagram username.
  2. Within 7 days we delete all data related to that account and its posts, add it to an exclusion list so it is not collected again, and confirm by reply.
  3. To disconnect a team account: in the Threads app go to Settings → Account → Website permissions and remove "Content Lab". The access token becomes invalid and the stored token and user ID are removed on the next scheduled run.
