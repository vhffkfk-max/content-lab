# 말희아빠 스튜디오

오뉴월드(@oh_neworld) 카드뉴스·릴스를 말희아빠 스타일로 만드는 프로그램입니다. Claude 는 이 PC의 Max 구독으로 불러서 API 요금이 없습니다.

위치는 `insta-research/ohneworld` 이고, 명령은 이 폴더에서 실행합니다 (2026-11-07부터 콘텐츠 연구소 안의 전용 폴더).
- 핫코노미 카드뉴스(`publish/`)·릴스(`reels/`)와 코드·설정을 섞지 않았습니다. 나중에 이 폴더만 통째로 빼면 됩니다.
- 백업·재료·결과 같은 개인 자료는 `.gitignore` 로 저장소에 올라가지 않습니다.

## 자주 쓰는 명령

```bash
python studio.py 새글
```
최근 글 목록을 갱신합니다 (공개 RSS 제목·요약 50개 + 바레이션).

```bash
python studio.py 만들기 blog:글번호
```
재료 폴더를 만듭니다. 차트가 없으면 여기서 멈추니, `재료/blog_글번호/` 에 블로그 원본 차트를 `차트1.png` 처럼 넣고 다시 실행합니다. 표지 사진을 정하려면 `표지.jpg` 를 넣습니다. 본문을 더 주려면 `글.txt` 에 붙여 넣습니다. 확인한 시세·실적은 `확인된수치.txt` 에 씁니다.

```bash
python studio.py 다시 결과폴더이름
```
`원고.json` 을 고친 뒤 그대로 다시 만듭니다 (Claude 를 부르지 않습니다). `--카드만`, `--릴스만` 을 붙일 수 있습니다.

```bash
python studio.py 전체분석
```
백업을 읽어 패턴 보고서를 만듭니다. 백업이 오면 이 명령 하나면 됩니다.

## 결과 폴더

`결과/날짜_제목/`
- `확인목록.txt`: **올리기 전에 먼저 봅니다.** 확인할 수치, 글 넘침, 받아쓰기, 차트 원본 일치 여부
- `원고.json`: 고칠 수 있는 원고
- `카드뉴스/`: 카드 JPG, `캡션.txt`, `캔바용.pptx`
- `릴스/영상.mp4`, `릴스/캡컷용/`

## 고치는 법

- **캔바:** `python studio.py 캔바 결과폴더이름` 을 실행하면 캔바 '오뉴월드 · 초안' 폴더에 올리고 편집 주소를 줍니다. 연결이 안 된 PC에서는 canva.com 에 `캔바용.pptx` 를 끌어다 놓습니다. 글자는 글상자, 차트는 따로 된 그림이라 각각 고칠 수 있습니다. 표지 사진은 그라데이션과 한 장으로 합쳐져 있어서, 바꾸려면 `재료/글폴더/표지.jpg` 를 넣고 `다시` 명령을 씁니다. 글꼴은 Noto Sans KR 입니다.
- **캡컷:** `python studio.py 캡컷 결과폴더이름` 을 실행하면 (캡컷이 켜져 있으면 스스로 닫았다가 다시 엽니다) 장면·음성·배경음·자막이 놓인 프로젝트가 생깁니다. 공식 기능이 아니라 캡컷이 업데이트되면 안 될 수 있고, 그때는 `릴스/캡컷용/안내.txt` 대로 직접 가져옵니다. 완성본, 장면별 영상(글자·소리 없음), 음성, 배경음, 자막(SRT), 차트 원본이 들어 있습니다. 캡컷 프로젝트 파일은 아닙니다.
- **빠른 수정:** `원고.json` 을 고치고 `다시` 명령을 씁니다.

## 백업 넣는 곳

- `백업/네이버/`: 네이버 콘텐츠 백업 (압축 파일 그대로 가능)
- `백업/인스타/`: 인스타 '내 정보 내보내기'. **JSON 형식**으로 요청합니다.
- `성과/수치.csv`: 있으면 성과까지 분석합니다. 첫 줄은 `날짜,캡션앞부분,주소,도달,저장,좋아요,댓글,공유`

`python studio.py 점검` 으로 먼저 확인합니다. 형식이 다르면 `분석/백업_점검.md` 를 보고 `studio/formats.json` 을 고칩니다. DM·댓글·개인정보 폴더는 열지 않고, 압축도 풀지 않습니다.

## 지키는 것

- 차트 원본은 자르기·보정·재작도하지 않습니다. 언론사 기사 캡처는 쓰지 않습니다.
- 자료에 없는 숫자와 투자 권유 표현은 코드가 막습니다. 그래도 게시 전 사람이 확인합니다.
- 자동 게시가 없습니다. 인스타 게시 화면의 AI 표시를 켜고, 영상의 'AI 음성' 표시를 지우지 않습니다.
- 말희아빠 목소리는 본인 동의 없이 복제하지 않습니다. 기본 음성은 Supertonic M3 입니다.
- 블로그 글 목록·본문을 자동으로 긁지 않습니다. 지난 글은 공식 백업으로만 받습니다. 새 글의 차트는 사람이 넣습니다.
- 백업, 재료, 결과, 분석은 공개 저장소에 올리지 않습니다 (`.gitignore`).

## 다른 PC로 옮길 때

필요한 것: Python 3.12 (requests, pydantic, pillow, python-pptx, playwright, numpy, pymupdf), Chrome, FFmpeg, Noto Sans KR, Claude Code 로그인, Supertonic 환경. 경로는 `config.json` 에서 고칩니다. `variation_json` 은 연구소 파일이라 분리 후에는 RSS 요약만 들어옵니다.

시험: `python -m unittest discover tests` (가짜 파일만 씁니다)
