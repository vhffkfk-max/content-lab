# 카드뉴스 디자인 근거 (2026-11-02)

연구소가 지켜보는 경제 계정 16곳의 캐러셀 50개(365장)를 내려받아, **같은 계정 안에서** 좋아요가 계정 중앙값보다 크게 높은 글과 낮은 글을 나란히 봤다.
이벤트·광고·당첨 글은 뺐다. 이미지는 `output/cardnews/bench2/`(저장소에 안 올림), 목록은 같은 폴더 `index.json`.

**한계:** 숫자는 좋아요·댓글뿐이다. 남의 글은 저장·공유·도달을 볼 수 없다. 좋아요에는 주제의 영향이 섞여 있다(정치·사건 뉴스가 특히 높음). 디자인만의 효과로 증명된 것이 아니라 '잘 되는 글의 공통점'이다. @hotconomy 글이 쌓이면 `card_learn.py` 의 실제 성적으로 다시 판단한다.

## 우리 카드에서 바꾼 것

- 예전: 글이 위쪽에 몰려 아래 절반이 비고, 본문이 휴대폰에서 작고, 표지가 글자 위주에 제목이 주제 요약.
- **사진 뉴스형(news)을 기본으로:** 표지는 사진 전체에 아래쪽 큰 제목, 본문은 위쪽 사진에 아래쪽 큰 글.
- **제목 크기를 줄 길이에 맞춤:** 가장 긴 줄이 폭에 꽉 차도록(`forms.fit`).
- **사진을 눈으로 고름:** 위키미디어 후보 최대 6장을 Haiku 에게 보여 주고 고름. 맞는 게 없으면 사진을 빼고 글을 가운데 크게(`photos._eye`).
- **숫자·막대·에디토리얼도 빈 공간 제거:** 세로 가운데 배치, 글자 키움.
- 새 초안 폼을 4개로 좁혔다가, 사진 뉴스형만 돌려쓰기 예외라 11/04 초안 8개가 전부 같은 모양이 됐다. 8가지(`forms.ACTIVE`)로 넓히고 최근 4개 글에 쓴 폼은 예외 없이 뺀다. 새로 넣은 4개(속보·리스트·인사이트·신문)는 빈 공간을 없애 다시 그렸고, 벤치마크 근거가 아니라 다양성 때문에 넣은 것이라 `card_learn` 성적으로 다시 판단한다.
- 사진 없는 본문 줄이기: 본문 모든 장에 검색어 필수, 못 찾으면 표지 인물의 다른 사진, 주가 장은 실제 시세 그래프(한 글에 1장). 그래도 없으면 표지 사진을 어둡게 깔고 강조 단어를 아주 크게.
- 표지가 비지 않게: 한국 경영인은 무료 사진이 거의 없다(조원태 표지가 빈 채로 나옴). 표지에 대체 검색어(bg_alt)를 받고, 그래도 없으면 본문 사진을 빌리며, 끝내 없으면 경고한다.
- 올리는 법: 4:5 를 1:1로 올리면 위아래 135px가 잘린다(@hotconomy 첫 글에서 확인). 한때 글을 가운데 1:1 안에 몰았으나, 폰에서 ⤢ 로 4:5 업로드가 되는 걸 확인해 다시 4:5 전체를 쓴다. 쪽 번호는 인스타가 보여 주니 뺐다. 초안 검사가 가장자리에 붙은 글을 경고한다.
- 프로필 격자: 격자는 3:4로 보여서 4:5 글은 좌우 34px씩 잘린다. 글은 x 44~1036 안에 둔다(1:1로 올린 글은 격자에서 좌우 135px가 잘린다). 3:4(1080×1440)는 토스·뉴닉이 쓰지만, 메타 발행 API 허용 범위가 4:5~1.91:1이라 연구소 발행을 생각해 4:5를 유지한다.
- 사진 출처: 카드 위 작은 글씨가 싸구려처럼 보여 빼고 캡션 끝에 모아 적는다. CC BY 계열은 출처 표시가 조건이라 아예 지우면 안 된다.
- 스킬 기준 보완(2026-11-05): 끝 장을 포함한 모든 장에 @hotconomy 를 넣어 캡처가 퍼져도 계정을 찾게 했다. 기본 장수를 5~7장에서 6~8장으로 늘렸다(재료가 모자라면 5장). 캡션은 `caption_check` 가 바로 고칠 것은 고치고, 잘못 올라가면 안 되는 것만 경고로 막으며 나머지는 텔레그램에 참고로 붙인다.
- 확인은 연구소 사이트에서: '카드뉴스 발행'에 장별 미리보기를 넣었다. 그림은 `card-previews` 가지에 최근 7일 치 저화질만 둔다(`publish/card_preview.py`). 텔레그램은 알림과 원본 저장용.
- BGM: 캐러셀에 음악을 붙이는 API를 찾지 못했다(오디오 API 문서는 릴스만, 2026-11 확인). 음악을 넣는 글은 폰 앱으로 올린다. 초안의 `bgm`(분위기, 앱 검색어, 피할 분위기)을 사이트와 텔레그램에 보여 주고 곡은 사람이 듣고 고른다. 곡명은 추천하지 않는다.
- 초안마다 이유를 남김: 큐 `design_why`(Claude 가 쓴 이번 글의 이유 + 폼의 근거), 사이트 '왜 이렇게 만들었나요'와 텔레그램에 표시.
