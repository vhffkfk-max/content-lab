안드로이드 '기타 파일' 찾기 / 정리 도구 (Windows)
=================================================

[준비 - 폰에서 1번만]
1. 설정 > 휴대전화 정보 > 소프트웨어 정보 > "빌드번호"를 7번 연속 탭
   -> "개발자 모드를 켰습니다" 메시지
2. 설정 > 개발자 옵션 > "USB 디버깅" 켜기
3. USB 케이블로 PC와 연결 (데이터 전송되는 케이블이어야 해요)

[실행]
1. 이 폴더를 통째로 PC 바탕화면 등에 압축 풀기
2. android_storage.bat 더블클릭
   - 처음 한 번은 Google 공식 ADB 도구(약 10MB)를 자동으로 받아요
   - 폰에 "USB 디버깅을 허용하시겠습니까?" 창이 뜨면 [허용]
   - "Windows의 PC 보호" 파란 창이 뜨면: 추가 정보 > 실행

[메뉴]
1. 전체 요약      : 폰 사용량 / 폴더 합계 / 앱 합계를 비교해서 기타 파일이 어디 있는지 진단
2. 폴더 탐색&삭제 : 큰 폴더 순서대로 보여줌. 번호로 들어가고, "d 번호"로 삭제
3. 큰 파일 찾기   : 200MB 넘는 파일 목록, "d 번호"로 삭제
4. 앱별 용량 순위 : 어떤 앱이 데이터를 많이 먹는지
5. 앱 캐시 정리   : 모든 앱의 임시 캐시만 지움 (사진/채팅/로그인 안전)

[주의]
- 삭제는 휴지통 없이 바로 지워져요. 지우기 전에 반드시 "yes"를 입력해야 해요.
- Android/data/앱이름 폴더를 지우면 그 앱의 오프라인 저장 영상, 받은 파일 등이 사라질 수 있어요.
- DCIM(사진), Download 등은 백업했는지 확인하고 지우세요.
- 다 쓰면 개발자 옵션 > USB 디버깅은 다시 꺼두는 걸 추천해요.
